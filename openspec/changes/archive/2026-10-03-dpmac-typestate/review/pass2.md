## Mandate verdicts (evidence for synthesis)

**(a) P4 isomorphism — HOLDS, with one guard asymmetry (F1/F2).** Every model sum/payload/pure-def has a same-named Rust twin in `crates/dpaa2-api/src/families/dpmac.rs`: `BOOT_MAC` ([2,0,0,0,0,7] both sides), `LinkType`/`FecMode`/`EthIf`/`DpmacAttributes`/`BOOT_ATTRS`/`StableAttributes`+`stable_attributes`, `LinkStateUp`/`BOOT_LINK_STATE`, `RequestsDownChannel`, `Counter`/`ALL_COUNTERS`/`COUNTERS_1039`/`COUNTERS_1040_EXT`/`FirmwareVersion`/`counter_vocabulary`/`read_counter`, `Arbitration`/`PeerObservation`/`PEER_OBSERVATIONS`/`standalone_bound_for`/`judge_arbitration`, `KernelFace`/`SeveredWitness`. camelCase→snake_case is the only rename. The requests-down channel is unreadable by construct on both sides: one payload-free constructor (`dpmac.qnt:152`, `dpmac.rs:177-181`) and **zero Rust consumers anywhere** (grep: only the definition) — no path can produce a read. The `read_counter` raw-value parameter is the one shape difference and is declared as deliberate at `dpmac.rs:265-267`. Rust-only types (`DpmacObservation`, `CounterReadout::VersionSignal`, `CarrierSource/CarrierReading`, `MacRelation`) are each documented as D4/D5/D6 decisions outside the qnt — protected, not iso gaps.

**(b) Edge law two-sided — HOLDS at the ordering level, weaker than claimed at the type level (F1).** `edgeDemandsSeveredWitness` is dpni↔dpmac only (`connect.qnt:42-43`), other kinds vacuous (`nonDpmacEdgesNoWitnessTest`, dpmac.qnt:602-611). Rust has exactly one `Unbind` variant, always dpmac-facing, carrying the proof — no leak onto other edge kinds (none exist on the plan surface). Negative face holds twice: Quint `.fail()` (dpmac.qnt:583-586) and the `compile_fail` doctest (transition.rs:161) plus the runtime twin `inverted_edge_trace_is_rejected` (dpmac_replay.rs:273-286). But "sever consumes KernelOwned and yields Offered plus the witness" is true only in Quint; the Rust `sever` consumes nothing — see F1.

**(c) Replay coverage.** 8 frozen traces = 8 TRACES rows, orphan-guarded. Arms driven per replay: `offeredAtBootTest` 0 transitions (boot-state check only); `kernelOwnedOnConnectTest` 1 arm (SameContainerKernelPeer); `remoteOwnedOnCrossContainerTest` 1 arm (CrossContainerPeer); `arbitrationHandbackTest` 2 arms; `arbitrationLawTest` all 3 `observeArbitrationAt` arms; `severThenUnbindTest` and `severOrderLawTest` 3 arms each (`kernelDpniTakesPortAt`, `severAt`, `unbindKernelFaceAt` enabled); `hazardUnbindBeforeSeverRefusedTest` 2 (take-port + the unbind refusal arm — the only refusal replayed, and the one the law targets). Additionally DPMAC-I2/I3/I6/SeverOrder are re-asserted at **every state of every trace** (`check_state`, dpmac_replay.rs:93-126), so the unfrozen `macAddressImmutableTest`/`attributeConstancyTest` are substantively covered; `counterVocabularyFirmwareIndexedTest`/`firmwareExtensionReadableAt1040Test` are covered by the proptest twin (dpmac_replay.rs:338-360) and the tile test. Arms with NO replayed trace: (1) `observeLinkStateUpAt` — both draws, zero replay and zero Rust-side consumer (the ITF reader deliberately skips the channel fields, dpmac_itf.rs:20-22; see F3); (2) `kernelDpniTakesPortAt`'s disabled face (not Offered) — no directed run on either side; (3) `severAt`'s disabled face (no kernel face) — no directed run, and no Rust refusal exists to twin it (F1/F2). COVERAGE's rows say "directed run", which is accurate (model CI), so no COVERAGE doc-drift from the replay subset.

**(d) Typed judgments — HOLD.** `MacRelation` and `CounterRead` are sum types on both consuming sides (status.rs display path, replay proptests); Pending is the first structural branch of `judge_mac_relation` (dpmac.rs:526-527), never a string compare; `CounterRead::NotInVocabulary` is a distinct constructor, proptested `!= Known(0)` for every raw value. The one sentinel zero on the judgment path (status.rs:134 `unwrap_or(MacAddr::ZERO)`) feeds ZERO→Pending, the non-drift class — benign and display-only. The reconciler never consumes `MacRelation` (protected D5 "no new verb"), so Pending-never-drift holds there **vacuously**; the reconciler's own raw MAC comparison has no transient exclusion — F5.
