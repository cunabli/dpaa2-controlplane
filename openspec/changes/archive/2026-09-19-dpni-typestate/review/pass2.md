# Pass 2 — Isomorphism and the typestate law (dpni-typestate)

Scope files read in full; verdicts first, ledger second, evidence tables third. No Pass 1 finding re-raised; the two open questions are dispositioned under (b) and (c).

## Verdicts by mandate

**(a) Create-surface isomorphism — HOLDS.** Option-for-option (10 `DpniOpt`, 2 `RawEscape` with matching `rawValue` 0x80000000/0x4000, 12 `Unrepresentable`, 4 `InterfaceConstruct`, 2 profiles with identical masks and cfg literals), range-for-range (all ten HI bounds identical, same `0 or 1..=HI` semantics), refusal-for-refusal. One recorded structural mapping: the model's 3-arm `Refusal` sum is deliberately split across three Rust homes (`RangeViolation` → range constructors' `Error::Config`; `DeadOptionRefusal` → `DeadOptionRefusal` struct; `UnpricedDataplane` → `ProfileOutcome::Unpriced`), documented at `families/dpni.rs:788-794` and reunified as the 3-arm `DpniRefusal` in the verify twin — acceptable under ADR-0002, with one naming nit (F4). The "unrepresentable" claim is honestly advertised — see the compile-vs-runtime table; no runtime refusal is dressed up as a typestate.

**(b) guu.4a fence — TWO-SIDED; mandate satisfied; one replay-rung gap filed (F2), one literal-duplication hazard filed (F1).** Same predicate both sides: `refuse.qnt:286` (`t > 32`) / `:291` (`cpus > 32`) ↔ `refuse/tenant.rs:107` / `:119` (`> NumQueues::HI`, HI=32). `project()` predicts the read-back on both sides: `dpni.qnt observe` (:271-280, cleared bits stripped, `num_cgs` CustomCg-gated, `num_opr` HasOpr-gated with 0→8 fill) ↔ `DpniObservation::project` (`families/dpni.rs:882-908`, identical arithmetic). `scenarioEnvelopeRefusedTest` is frozen and replayed: `dpni_replay.rs:45-48` drives the refusal arm and `witness_refusal` (:118-123) asserts `NumQueues::new(33).is_err()`.
**Pass 1 open question 1 disposition:** the frozen trace replaying `RangeViolation` is *correct*, not a defect — `scenarioEnvelopeRefusedTest` is a `dpni_scenario` (family-surface) run, and `RangeViolation` IS that surface's refusal arm for an off-envelope cfg; `QueueEnvelopeExceeded` is the *intent-layer* twin of the same predicate. The intent arm holds two-sided by unit test (`compile_tests.rs:437-489`, both poll and kernel shapes) plus the simulate witness `wQueueEnvelopeExceeded` (`package.json:6`); its ITF decoder arm (`intent_itf.rs:770`) is dead against the committed corpus — the frozen intent RefusedTraces are only the four scenario twins (`models/intent/replay.qnt:47-55`). This **satisfies** the mandate (the fence's semantics are pinned on both surfaces by tests that fail on drift) but leaves the replay rung blind to the intent arm — filed as F2, not as a mandate breach.

**(c) ITF replay coverage — mapped; two gaps named.** Trace → model transition: Pmd/Kernel readback → `createDerivedAt` Derived arms; EnvelopeRefused → `createRawAt` refuse arm; DeadOption/NumRxTcs → `createUnrepresentableAt`; WriteOnlyDistKeySize → `createRawAt` accept arm; PrimaryMacMutation → `createDerivedAt` + `setPrimaryMacTo`. Arms with **no** replayed trace: `createDerivedAt`→Unpriced (Pass 1 F4, not re-raised); **1 of 11 dead-option arms replayed** (`MaxSenders` only; +`NumRxTcs` = 2 of 12 unrepresentable arms) — intended-sufficient: all eleven flow through one parameterized action with identical semantics, and per-name parity is pinned by `every_unrepresentable_item_fires_a_named_refusal` + the ADR-0014 variant lists; `destroy` — deliberately excluded from the scenario module (documented, `dpni.qnt:615-624`), report-only.
**Pass 1 open question 2 disposition — split:** `TxFrmRelease`/`HasPolicing`/`NoMacFilter`/`StashingDis` decoder arms are **intended** (decoder totality over the vocabulary, the dprc precedent; those flags ride no profile and carry no per-flag law). `SharedCongestion` + `RawEscape::HasReplication` are a **freeze-set gap** (F5): they carry the McClearedFlags law — the newest board-verified 5.2 behavior — and no scenario run exists to freeze that face; combined with Pass 1 F3 (parser can't decode `HasReplication`), the face is doubly unreachable by replay.

**(d) D4 write-only law — HOLDS, with one claimed-set breach (F3).** Model `Observation` (`dpni.qnt:246-252`) omits `distKeySize` and `rootContainer` structurally; Rust `DpniObservation` (`families/dpni.rs:840-862`) omits both **by construct** — no field exists, no runtime skip anywhere (`drift_disposition` compares projections; the replay compares `Observed`, and `dpni_replay.rs:183-189` makes the invariance load-bearing on every created trace). Shim edge: `RawDpniAttr` (`parse.rs:253-311`) keeps split `num_rx_tcs`/`num_tx_tcs` and added `qos_key_size`/`fs_key_size` on the raw struct; `map_dpni_observation` (`restool.rs:153`) maps only domain fields; tests at `restool.rs:1700,1721-1725` assert no leak into the pure core's equality. Exception: `wriop_version` is *claimed* kept (spec delta + design) but the parser has no field for it — F3.

## Compile-time vs runtime-refusal table ("unrepresentable" claim)

| Invalid configuration | Mechanism | Compile-time or runtime | As advertised? |
|---|---|---|---|
| Dead option / `num_rx_tcs` on a create | no `DpniCfg` field; `Unrepresentable` exists only to name the refusal | **compile-time** (unrepresentable); runtime `DeadOptionRefusal` is the parity *answer*, not the guard | yes |
| Unnamed MC flag (4 of 14) / arbitrary raw mask bit | no `DpniOpt`/`RawEscape` variant; `OptionMask` additive-only | **compile-time** | yes |
| Create-time MAC | no cfg field; MAC is runtime-only (`set_primary_mac`) | **compile-time** | yes |
| Mutating the create block post-create | no `&mut cfg` path; `cfg()` returns `&DpniCfg` | **compile-time** (witnessed by `compile_fail` doctest, :594-600) | yes |
| Out-of-envelope numeric (e.g. num_queues 33) | smart constructor `T::new` → `Result` | **runtime** rejection of raw input; the *value type* has no out-of-envelope inhabitant, so `DpniCfg` cannot be built with one | yes — docs say "type-boundary error, not a board rejection" (:82-83); not oversold |
| Operator-supplied option token on the compile path | witness constructors derive cfg from `Dataplane` only | **compile-time** (no parameter to pass) | yes |
| Third profile / per-interface option override | `Profile` has two variants; `derive_profile` total | **compile-time** | yes (D3) |
| `UserspaceEvent` dpni | `ProfileOutcome::Unpriced` / intent `UnpricedDataplane` | **runtime** typed refusal | yes — advertised as refusal |
| Derived T/cpus > 32 (intent level) | `Refusal::QueueEnvelopeExceeded` | **runtime** typed refusal | yes (guu.4a records it as a refusal, not a typestate) |
| Hand-built plan with off-envelope num_queues via pub witness | silent degrade to `NumQueues::DEFAULT` | **neither** — no refusal fires outside compile | **gap** — F6 (documented only as "undefined on refused intents") |

**Net verdicts for synthesis:** (1) the core promise holds — invalid create configurations are unrepresentable where claimed and typed-refused where recorded, with the smart-constructor runtime boundary honestly documented; the one soft spot is F6's unfenced pub-constructor face. (2) ADR-0002 compliance: **yes** — structurally isomorphic including the guu.4a fence, with F1 (model-side fence-by-literal) as the standing hazard and F2/F5 as replay-coverage debt, not structure debt. Rule-amendment nomination for the judge: F1 is direct evidence for the brief's guu.4a rule-candidate — a fence constant that exists in one artifact by reference and in its twin by literal is exactly how a refined range lands one-sided; a rule "a shared bound is named once per artifact and imported, never restated as a literal" would have prevented both the original guu.4a divergence and F1.
