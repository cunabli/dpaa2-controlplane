1. **Aged-board offline gate — NOMINATE, narrow.** b4c shipped through sealed groups with green gates because every fake/census fixture modeled a fresh board where `free = ceiling − population` holds; the silent create=0 plan was only reachable when that identity broke. Decline the blanket form ("all suites model aged boards"): most judgments don't read free counts and the cost lands everywhere.
2. **Board-vs-fixture name-drift pre-sitting lint — NOMINATE, as an extension of the existing offline-pin idiom.** rev4e burned two sittings on a driver-basename mismatch (`fsl_dpaa2_eth`) that an offline comparison would have caught; the existing stop-after-two-kills rule is reactive. Extension: the vrollback1_intents-style pin tests already pin the grep shapes the scripts run — add a pinned board-facts record (driver basenames, sysfs path shapes observed on the board) that suite-authored kernel-facing literals must match, checked pre-sitting with the other offline pins.
